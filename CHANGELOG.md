# Changelog

All notable changes to this project will be documented in this file.

## [0.1.4]

### Added

- Support for opening a different entity with `tap_action.entity`.

## [0.1.3]

### Fixed

- Fixed unit display for climate attributes.

## [0.1.2]

### Fixed

- Fixed text color in secondary rows.

## [0.1.1]

### Added

- Climate mode icons.
- Climate entity support in select controls.

### Improved

- Improved mobile layout.
- Reduced temperature control value size.
- Improved secondary rows.
- Improved entity handling for controls.
- Improved value formatting.

## [0.1.0]

### Added

- Initial public release.
- Number (+/-) controls.
- Power button.
- Climate HVAC mode selector.
- Multiple secondary rows.
- Multiple entity support.
- Advanced value formatting.
- Standard Home Assistant actions.
- Initial documentation and examples.
