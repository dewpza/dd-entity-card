# Roadmap

This document outlines the planned development of DD Entity Card.

The roadmap may change as new ideas and community feedback arrive.

---

# Version 0.1

Initial public release

## Features

- Entity card
- Number control
- Switch control
- Climate mode selection
- Multiple secondary rows
- Multiple entity support
- Styling options
- Home Assistant actions

---

# Version 0.2

## Climate improvements

- Climate mode icons
- Fan mode selector
- Preset mode selector
- Swing mode selector

## UI

- Better spacing
- Compact layout
- Improved mobile layout

---

# Version 0.3

## New controls

- Slider
- Cover position
- Light brightness
- RGB color picker
- Percentage controls

## New features

- Conditional visibility
- Dynamic icon colors
- Better animations

---

# Version 0.4

## Card improvements

- Horizontal mode
- Compact mode
- Auto layout
- Responsive controls

---

# Version 1.0

## Stable Release

- Stable API
- Complete documentation
- Full HACS support
- Extensive examples
- Localization
- Optimized rendering
